## Warning

**This tool is dangerous. Use it at your own risk.**

Incorrect images, wrong partition selection, or interrupted flashing may cause permanent data loss or a **hard brick**, potentially making your device unrecoverable.

Always verify image compatibility and back up your data before flashing.

The developer is not responsible for any damage caused by using this tool.
